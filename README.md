# TalentAI – Explainable AI Resume Intelligence System

An AI-powered resume intelligence platform that performs semantic resume matching, explainable ranking, and intelligent candidate shortlisting using local LLMs and embedding models.

## Tech Stack

- FastAPI
- MongoDB
- ChromaDB
- Qwen 3 8B Instruct
- BAAI/bge-small-en-v1.5
- Cross Encoder
